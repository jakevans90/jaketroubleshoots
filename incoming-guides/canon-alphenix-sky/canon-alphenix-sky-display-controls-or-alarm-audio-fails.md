## What This Guide Helps With
Troubleshoot blank or abnormal displays, unresponsive controls, failed audible indications, loose connections, settings, or system communication problems.

## Step-by-Step Troubleshooting
### 1. Protect the Patient and Stop Unsafe Operation
Do not continue using the angiography system if required displays, controls, or audible safety indications are unavailable or unreliable during patient care.

**Expected outcome:** The patient is moved to a safe alternative workflow before troubleshooting affects clinical operation.

### 2. Define the Failed Function
Determine whether the problem affects one display, all displays, a specific operator control, touchscreen, keyboard, foot control, hand control, or audible indication.

**Expected outcome:** The problem is isolated to a specific interface or identified as a broader system failure.

### 3. Check Overall System Operation
Confirm whether the rest of the system is powered and responsive. Observe system status indicators and determine whether the affected interface alone is unavailable.

**Expected outcome:** The failure is separated into an isolated interface issue or a system-wide condition.

### 4. Inspect Accessible Connections
Check display cables, control cables, external interface connections, accessory controls, and approved power connections for looseness, damage, or strain.

**Expected outcome:** External connections are secure and undamaged.

### 5. Verify Accessible Display and Audio Settings
Check normal user-accessible brightness, display selection, audio level, mute status, and related operating settings where applicable. Do not change restricted configuration.

**Expected outcome:** The failure is not caused by an accessible setting. Correcting the setting restores function if it was the cause.

### 6. Check for Obstruction or Contamination
Inspect touch surfaces, control panels, switches, and external controls for covers, contamination, fluid residue, or physical obstruction that could interfere with operation.

**Expected outcome:** Controls are clean, unobstructed, and mechanically usable.

### 7. Compare or Substitute External Components
Where compatible components are externally interchangeable, test with a known-good control, display connection, cable, or peripheral as appropriate.

**Expected outcome:** The substitution identifies an external component failure or confirms that the problem remains with the system.

### 8. Perform an Approved Restart
With the patient safely separated from the equipment and no evidence of physical or electrical damage, perform a normal system restart.

**Expected outcome:** Displays, controls, and audible indications initialize normally. If all required functions remain stable, troubleshooting can stop after verification.

### 9. Verify Required Safety Functions
Confirm the affected controls respond consistently and verify required audible and visual system indications using appropriate functional testing.

**Expected outcome:** User interfaces and required indications function reliably before clinical use.

### 10. Escalate Any Persistent Interface Failure
If a required display, control, or alarm-related audio function remains unreliable, remove the system from service.

**Expected outcome:** Equipment with an unreliable operator or safety interface is not returned to clinical use.

## If the Problem Persists
External connections, accessible settings, contamination, peripheral components, and normal restart have been checked. Remaining possibilities include internal display electronics, control interfaces, audio circuitry, software, communication, or configuration.

Remove the system from service, label it **Out of Service**, and arrange qualified service evaluation using manufacturer documentation and approved test equipment. Do not return the system to use with required displays, controls, or audible indications disabled.

Return to service only after affected functions and relevant safety indications have been fully verified. Knowing when to stop external troubleshooting is proper troubleshooting.

## Clinical Use Tip
A working imaging chain is not sufficient for clinical use if the operator cannot reliably see system status, control the equipment, or receive required safety indications.

## Final Thought
Treat failed operator and safety interfaces as clinically significant, rule out simple external connections and settings first, verify all affected functions, and escalate whenever reliable operation cannot be demonstrated.
