## What This Guide Helps With

An anesthetic-agent module is absent, unrecognized, or does not deliver because of installation, compatibility, agent level, connection, or service-level faults.

## Step-by-Step Troubleshooting

### 1. Protect the Patient and Maintain Anesthesia
Do not troubleshoot an unavailable or unreliable anesthetic-agent delivery system while a patient depends on it. Transition the patient to a verified alternative anesthesia delivery method before technical work.

**Expected outcome:** Patient anesthesia is maintained independently, and the affected Flow-e can be safely evaluated.

### 2. Confirm the Complaint
Determine whether the module is completely unrecognized, recognized but unavailable, recognized but not delivering agent, or intermittently disconnecting.

Record any exact on-screen message without interpreting it beyond what is displayed.

**Expected outcome:** The failure mode is clearly identified and reproducible.

### 3. Verify Correct Module Installation
Confirm the vaporizer or agent module is correctly seated in its intended position and fully engaged.

Remove and reinstall it using normal approved handling procedures if necessary.

**Expected outcome:** The module seats securely and is recognized. If reseating resolves the issue, complete gas-delivery verification before stopping troubleshooting.

### 4. Verify Compatibility and Agent
Confirm the installed module is the correct compatible type for the Flow-e configuration and contains the intended anesthetic agent.

Do not attempt to modify coding, identification, or service configuration to force recognition.

**Expected outcome:** The installed module is appropriate for the system and clinical application.

### 5. Inspect the Module Externally
Check for visible damage, contamination, liquid spills, cracked housings, damaged accessible contacts or interfaces, improper closure, or other abnormal condition.

If the module is damaged or leaking, remove it from service.

**Expected outcome:** No obvious external damage or unsafe condition is present.

### 6. Check Agent Level and Filling Condition
Verify sufficient agent is present and that the fill area is properly closed and free from obvious leakage.

Follow facility and manufacturer handling requirements for anesthetic agents.

**Expected outcome:** Adequate agent is available and there is no visible leak or filling-related problem.

### 7. Substitute a Known-Good Compatible Module
If available, install an approved known-good compatible vaporizer or agent module and repeat recognition and delivery testing.

**Expected outcome:** If the known-good module operates correctly, the original module is isolated as the suspect component and should remain out of service.

### 8. Verify Agent Measurement Path
Inspect the analyzer sample line and water trap and confirm the agent measurement channel is producing stable readings during controlled test delivery.

A functioning delivery module may appear ineffective if the measurement pathway is compromised.

**Expected outcome:** Agent measurement responds to controlled delivery. If correcting the sampling path resolves the complaint, troubleshooting can stop after complete checkout.

### 9. Perform Controlled Agent-Delivery Verification
Using approved anesthesia test equipment in a properly ventilated test environment, verify agent delivery and measurement according to applicable manufacturer procedures.

**Expected outcome:** Agent delivery responds to commanded changes and is verified within applicable manufacturer criteria. Complete checkout before return to service.

### 10. Escalate if Recognition or Delivery Remains Unreliable
If multiple known-good compatible modules are not recognized or agent delivery cannot be verified, stop external troubleshooting.

**Expected outcome:** The Flow-e remains removed from service for qualified repair evaluation.

## If the Problem Persists

External installation, compatibility, agent availability, module condition, and sampling-path problems have been ruled out. Remaining causes may involve the machine's internal module interface, identification circuitry, internal agent-delivery control, analyzer components, calibration, software, or service configuration.

The machine should be:

- Removed from service.
- Labeled Out of Service.
- Sent for repair or bench evaluation.
- Evaluated using approved Getinge service documentation and test equipment.
- Repaired or configured only by qualified personnel.

A suspect agent module should also be clearly identified and isolated from clinical inventory.

Do not return the system to service until agent recognition, delivery, measurement, alarms, and full anesthesia-machine checkout are verified.

## Clinical Use Tip

Never assume agent is being delivered simply because a vaporizer or agent module appears physically installed.

## Final Thought

Confirm correct installation, compatibility, agent availability, and measurement before assuming an internal delivery problem, and remove the system from service whenever anesthetic-agent delivery cannot be reliably verified.
