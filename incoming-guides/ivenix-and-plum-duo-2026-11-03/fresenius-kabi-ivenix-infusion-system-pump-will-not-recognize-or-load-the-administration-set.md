## What This Guide Helps With

Administration set loading, detection, door/retainer engagement, tubing placement, damaged disposables, contamination, or external sensor-area problems preventing setup.

## Step-by-Step Troubleshooting

### 1. Protect the Patient and Maintain Therapy

If the pump is connected to a patient and therapy cannot safely be interrupted, transfer the infusion to another verified pump using appropriate clinical procedures before troubleshooting. Do not repeatedly manipulate the set while the patient depends on the affected channel.

Expected outcome: Patient therapy is maintained on reliable equipment and the affected pump is available for safe evaluation.

### 2. Confirm the Exact Reported Condition

Determine whether the pump will not accept the set, will not complete loading, reports the set as absent, repeatedly releases it, or fails only with a particular set. Note whether the problem occurs before or after the pumping mechanism engages.

Expected outcome: The failure is reproduced or clearly characterized. If the problem cannot be reproduced and the pump passes functional verification with an approved set, troubleshooting can stop after documentation.

### 3. Inspect the Administration Set

Verify that the administration set is the correct approved type for the Ivenix Infusion System. Inspect the cassette/tubing interfaces for deformation, damaged components, contamination, kinks, or packaging damage.

Expected outcome: The set is correct and physically intact. If replacing a damaged or questionable disposable resolves the problem, troubleshooting can stop after verification.

### 4. Verify Set Orientation and Routing

Reload the administration set according to the approved loading path. Confirm that tubing is fully seated, not twisted, stretched, doubled over, or trapped outside its intended guides.

Expected outcome: The set seats normally and the pump recognizes it. If recognition is restored, complete a functional check and stop troubleshooting.

### 5. Inspect the Loading Area

With the pump removed from clinical use, inspect accessible set-loading surfaces, guides, retainers, doors, and sensor windows for dried fluid, adhesive residue, foreign material, or physical obstruction. Clean only using approved methods.

Expected outcome: The loading area is clean and unobstructed. If removal of an external obstruction restores normal loading, verify operation and stop.

### 6. Check Door, Latch, and Retainer Movement

Operate accessible loading components without forcing them. Look for looseness, binding, incomplete closure, cracked plastic, or a latch that does not remain securely engaged.

Expected outcome: All accessible loading components move freely and remain properly secured. Mechanical damage requires removal from service.

### 7. Try a Known-Good Administration Set

Use a new, known-good compatible administration set from a different package or lot when practical.

Expected outcome: A known-good set loads and is recognized. If so, suspect the original disposable or lot rather than the pump and document the comparison.

### 8. Compare With Another Known-Good Pump

If multiple sets fail in the affected pump, test one of those sets on another verified Ivenix pump when allowed by facility procedures.

Expected outcome: The comparison helps distinguish a disposable issue from a pump-specific problem. A pump-specific repeatable failure requires escalation.

### 9. Restart the Pump Outside Patient Use

If the loading mechanism appears normal but recognition remains unavailable, perform a normal power cycle with the device disconnected from patient therapy. Do not use unauthorized service functions or configuration changes.

Expected outcome: The pump completes startup and recognizes a properly installed set. If recognition returns and remains stable through repeated loading checks, troubleshooting can stop.

### 10. Perform Final Functional Verification

Load a known-good approved set and confirm the pump consistently detects it, accepts setup, completes the normal loading sequence, and shows no related alarms before returning it to service.

Expected outcome: Administration-set recognition is repeatable and reliable. If any part remains intermittent, remove the pump from service.

## If the Problem Persists

Common external causes such as incorrect disposables, damaged sets, improper routing, contamination, obstruction, and loading technique have been ruled out. A persistent problem may involve the loading mechanism, set-detection system, sensor alignment, mechanical components, or service-level configuration.

Remove the device from service, label it Out of Service, and send it for repair or bench evaluation. Evaluate it using appropriate Fresenius Kabi service documentation and approved test equipment. Internal repair or adjustment should be performed only by qualified personnel.

Do not return the pump to clinical use until administration-set detection, loading, pumping operation, alarms, and applicable performance testing are successfully completed.

Knowing when to stop external troubleshooting is proper troubleshooting.

## Clinical Use Tip

Never troubleshoot an unreliable set-loading mechanism while a patient depends on the affected infusion channel.
