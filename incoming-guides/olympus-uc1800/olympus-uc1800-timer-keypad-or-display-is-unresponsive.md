## What This Guide Helps With

Troubleshoot control-panel problems caused by power, contamination, stuck controls, operating state, connection issues, or external environmental conditions.

## Step-by-Step Troubleshooting

### 1. Protect Workflow and Remove Unreliable Equipment From Use
If the timer, keypad, or display cannot reliably control or indicate the cleaning cycle, remove the unit from active processing.

Do not use the cleaner if staff cannot verify cycle selection or completion.

**Expected outcome:** Instrument processing is transferred to another verified method while the unit is evaluated.

### 2. Confirm the Control Failure
Determine whether:
- The entire display is blank
- Only some display segments are missing
- One or more buttons are unresponsive
- The keypad responds intermittently
- The timer freezes
- Inputs register incorrectly
- Controls fail only during a particular operating state

**Expected outcome:** The control-panel symptom is clearly defined.

### 3. Verify Power
Inspect the power cord and plug and test the receptacle using an appropriate method.

Power the unit off and restart it using normal controls.

Observe whether the display initializes normally.

**Expected outcome:** Stable incoming power is confirmed and the control panel completes normal startup.

### 4. Inspect the Keypad and Display Surface
Check for:
- Cleaning solution residue
- Moisture
- Heavy contamination
- Torn or damaged keypad surfaces
- Cracked display areas
- Stuck or physically depressed buttons

Clean only according to approved procedures and do not allow additional fluid to enter the controls.

**Expected outcome:** The control surface is clean, dry, and free of obvious mechanical obstruction.

### 5. Verify the Unit Is Not in a Normal Locked or Active State
Determine whether controls are unavailable because:
- A cycle is already active
- A normal sequence must finish first
- Another selected function is preventing input
- A normal user-accessible control state is active

Do not enter service menus or alter undocumented configuration.

**Expected outcome:** Normal operating-state restrictions are ruled out.

### 6. Test Individual Controls
Using normal operation, check each relevant button one at a time.

Observe whether the display responds correctly to:
- Cycle selection
- Timer adjustment
- Heating control
- Start or stop commands
- Other normally available functions

**Expected outcome:** Each tested control produces the expected visible response.

### 7. Observe for Intermittent Behavior
Gently operate the controls normally without flexing or striking the panel.

Watch for:
- Flickering
- Delayed response
- Inputs that register multiple times
- Display resets
- Operation changing when the unit vibrates

If the problem disappears after cleaning or power correction and repeated testing is normal, troubleshooting can stop.

**Expected outcome:** Controls remain stable through repeated operation.

### 8. Complete Functional Verification
Run an applicable full test cycle and verify the timer progresses, controls remain responsive, and the displayed cycle status remains understandable throughout operation.

**Expected outcome:** The control interface functions consistently and supports safe return to service.

## If the Problem Persists

If incoming power, control-surface condition, operating state, and normal inputs have been ruled out, the issue may involve the keypad assembly, display, internal connections, control electronics, or power distribution.

The device should be:
- Removed from service
- Labeled Out of Service
- Sent for repair or bench evaluation
- Evaluated using appropriate manufacturer documentation and approved test equipment
- Repaired or configured only by qualified personnel

Avoid board-level troubleshooting or undocumented control-panel calibration. Complete operational and applicable electrical-safety verification after repair.

Knowing when to stop external troubleshooting is proper troubleshooting.

## Clinical Use Tip

A cleaner with an unreliable timer or display should not be used when staff cannot verify that the required processing cycle actually occurred.

## Final Thought

Control problems should be traced from power and surface condition through normal operating states before internal electronics are suspected. Reliable cycle indication must be confirmed before the cleaner returns to processing service.

That is successful troubleshooting.
