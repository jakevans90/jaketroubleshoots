## What This Guide Helps With

Troubleshoot startup and user-interface failures involving the display, touchscreen, foot pedal, external power, connections, or system control before service escalation.

## Step-by-Step Troubleshooting

### 1. Protect Clinical Workflow and Do Not Use an Unreliable Control Interface

Do not operate the sterilizer if staff cannot reliably view status, select required functions, or control the unit.

Move instrument processing to another verified sterilizer if necessary.

**Expected outcome:** The sterilization process does not depend on a partially functional control interface.

### 2. Confirm the Exact Symptom

Determine whether the issue is:

- No power
- Blank display
- Frozen startup screen
- Repeated restart
- Touchscreen not responding
- Only part of the touchscreen responding
- Foot pedal not responding
- Display visible but controls unavailable
- Failure only after startup

**Expected outcome:** The issue is separated into power, display, touch input, accessory input, or software/startup behavior.

### 3. Verify External Power

Inspect the power cord, plug, and connection for obvious damage or looseness.

Confirm the facility outlet or supply is available using approved methods and determine whether a breaker, disconnect, or facility outage is involved.

Do not repeatedly reset a breaker that continues to trip.

**Expected outcome:** Stable external power is available to the sterilizer.

If restoring a facility power connection resolves the issue and startup completes normally, continue to final functional verification.

### 4. Observe the Startup Sequence

Power the sterilizer normally and observe:

- Whether indicators activate
- Whether the display illuminates
- Whether startup progresses
- Whether the unit freezes at a consistent point
- Whether it restarts unexpectedly
- Whether an exact message appears

Do not access service menus or interrupt software initialization unnecessarily.

**Expected outcome:** Startup either completes normally or a repeatable failure point is identified.

### 5. Inspect the Display and Touchscreen Externally

Check for:

- Cracks
- Liquid intrusion
- Contamination
- Protective material interfering with touch
- Impact damage
- Delamination
- Unresponsive areas

Clean only using approved methods.

**Expected outcome:** The user interface is physically intact and free of external contamination that could interfere with operation.

### 6. Check the Foot Pedal and External Connection

If the complaint involves the foot pedal, inspect the pedal and accessible cable/connector for:

- Damage
- Loose connection
- Pinching
- Fluid contamination
- Strain
- Bent or damaged connector features

Reseat the connector if it is intended to be externally removable.

**Expected outcome:** The foot pedal is securely connected and free of obvious damage.

If reseating or replacing a damaged external accessory with an approved known-good unit restores function, troubleshooting can stop after verification.

### 7. Compare With a Known-Good Accessory When Available

For a removable foot pedal or other approved external control accessory, compare with a known-good compatible unit if available.

Do not substitute unapproved accessories.

**Expected outcome:** The fault is isolated to the accessory or the sterilizer interface.

### 8. Perform a Controlled Restart if Appropriate

If the unit is idle and no cycle is active, perform a normal shutdown and restart using approved procedures.

Do not repeatedly power-cycle a unit that is continuously restarting, overheating, or showing electrical abnormality.

**Expected outcome:** A transient interface or startup condition clears and the system starts normally.

If normal operation returns, continue with a full functional check before release.

### 9. Verify Complete User Interface Function

After any correction, confirm:

- Startup completes
- Display remains stable
- Required touch controls respond
- Foot pedal operates if applicable
- Cycle selection can be performed normally
- No repeated restart occurs

Run an approved verification cycle when required.

**Expected outcome:** The user interface remains reliable through normal operation and the verification cycle completes successfully.

If all functions pass, troubleshooting can stop.

### 10. Remove From Service for Persistent Startup or Control Failure

Remove the sterilizer from service if it:

- Will not complete startup
- Repeatedly restarts
- Has an unreliable touchscreen
- Has a blank or unreadable display
- Cannot reliably accept operator input
- Shows evidence of fluid intrusion, overheating, electrical damage, or internal failure

**Expected outcome:** An unreliable control system is prevented from affecting sterilization operation or load processing.

## If the Problem Persists

External power, physical controls, accessible connections, removable accessories, and a controlled restart have been checked.

Possible remaining categories include:

- Display assembly
- Touch interface
- Control electronics
- Power supply subsystem
- Internal cabling
- Software
- Boot storage
- Accessory interface electronics

The sterilizer should be:

- Removed from service
- Labeled Out of Service
- Sent for repair or qualified service evaluation
- Evaluated using appropriate ASP documentation and approved test equipment
- Repaired or configured only by qualified personnel

Do not perform board-level repair, unauthorized software recovery, or internal power-supply troubleshooting.

Following repair, verify startup, all operator controls, accessory operation, cycle completion, and required process documentation before return to service.

Knowing when an interface or startup problem has moved beyond safe external troubleshooting is proper troubleshooting.

## Clinical Use Tip

Do not rely on a sterilizer with a partially responsive touchscreen because an apparently minor input failure can prevent correct cycle selection or response to system prompts.

## Final Thought

Startup and interface failures should be approached by verifying external power, observing the exact startup behavior, inspecting controls and accessories, and using known-good substitutions where appropriate. Remove the sterilizer from service when operator control cannot be trusted, and document the final functional verification clearly.

That is successful troubleshooting.
