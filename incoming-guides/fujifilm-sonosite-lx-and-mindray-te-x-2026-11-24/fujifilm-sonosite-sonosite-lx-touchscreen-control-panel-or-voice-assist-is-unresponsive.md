## What This Guide Helps With

Troubleshoots unresponsive touchscreen, physical controls, or voice-assisted functions caused by contamination, settings, accessories, software state, or control failure.

## Step-by-Step Troubleshooting

### 1. Protect the Patient and Procedure
If controls cannot reliably change imaging parameters or perform required functions during a procedure, move clinical use to another verified ultrasound system before troubleshooting.

Expected outcome: Patient care continues without dependence on unreliable controls.

### 2. Confirm Which Controls Are Affected
Determine whether the touchscreen, physical controls, voice functions, or all input methods are affected. Note whether the display itself continues updating normally.

Expected outcome: The failure is isolated to one input method or confirmed as a broader system-control problem.

### 3. Inspect and Clean External Control Surfaces
Inspect the touchscreen and controls for fluid, gel, contamination, covers, labels, or objects that could interfere with operation. Clean only using facility-approved methods compatible with the equipment.

Expected outcome: Control surfaces are clean, dry, unobstructed, and responsive. If normal response returns, troubleshooting can stop after verification.

### 4. Check Physical Controls for Binding
Verify that accessible buttons, knobs, or other controls move normally and are not physically stuck, damaged, or obstructed.

Expected outcome: Controls operate freely without sticking or abnormal mechanical resistance.

### 5. Verify the Current Operating State
Exit any workflow, dialog, screen lock, or application state that legitimately limits control operation using normal user-accessible functions. Do not enter unauthorized service menus.

Expected outcome: Controls respond normally in standard imaging operation.

### 6. Evaluate Voice-Assist Conditions
If only voice-assisted operation is affected, verify the feature is enabled through normal clinical settings and that environmental noise is not preventing reliable recognition. Check any required external microphone or audio connection if applicable.

Expected outcome: Voice commands operate consistently under appropriate conditions. If touchscreen and physical controls remain normal, the issue is isolated to the voice-control path.

### 7. Perform a Controlled Restart
When patient care is not dependent on the system, shut down and restart using the normal power sequence.

Expected outcome: The system boots normally and all control methods respond consistently. If so, perform final verification and troubleshooting can stop.

### 8. Perform Final Functional Verification
Test representative touchscreen selections, physical controls, and voice functions if configured for use. Verify imaging settings respond correctly without unintended selections or repeated input.

Expected outcome: All required controls respond predictably and reliably.

## If the Problem Persists

External contamination, obstruction, operating state, accessible settings, and temporary software conditions have been ruled out. Persistent failure may involve the touchscreen assembly, control interface, audio subsystem, software, configuration, or other internal electronics.

Remove the system from service if required controls are unreliable. Label it **Out of Service** and send it for repair or bench evaluation using appropriate Fujifilm Sonosite documentation and approved test equipment. Configuration changes and repairs should be performed only by qualified personnel.

Complete applicable functional and safety testing after repair. Knowing when to stop external troubleshooting is proper troubleshooting.

## Clinical Use Tip

Do not continue a procedure when control input is delayed, intermittent, or produces unintended imaging changes.

## Final Thought

Reliable control input is essential for safe ultrasound operation. Start with external conditions and normal operating states, verify the correction, and escalate persistent control failures rather than assuming a specific internal component.

That is successful troubleshooting.
