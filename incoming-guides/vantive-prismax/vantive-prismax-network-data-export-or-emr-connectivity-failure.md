## What This Guide Helps With

Helps troubleshoot connectivity issues involving network access, data transfer, or clinical system communication.

## Step-by-Step Troubleshooting

### 1. Confirm patient safety and treatment operation
Ensure CRRT therapy is functioning independently of the communication issue and patient care is not dependent on unavailable data transfer.
**Expected outcome:** Patient therapy remains supported.
### 2. Confirm the communication failure
Verify whether the issue affects network connection, exported data, or EMR interface communication.
**Expected outcome:** The reported problem is identified.
### 3. Inspect external network connections
Verify visible network cables, connectors, and external connection points.
**Expected outcome:** Physical network connections are secure.
### 4. Verify network availability
Coordinate with appropriate IT resources to determine whether infrastructure issues affect communication.
**Expected outcome:** Network availability is confirmed.
### 5. Verify device configuration and connectivity status
Review approved device communication settings without making unauthorized configuration changes.
**Expected outcome:** Configuration concerns are identified or ruled out.
### 6. Perform final communication verification
Confirm successful data transfer or communication after correction.
**Expected outcome:** Connectivity is restored and troubleshooting can stop.

## If the Problem Persists

External connections, infrastructure concerns, and approved configuration checks have been ruled out.
The device should be:
- Removed from service only if clinical operation is affected
- Labeled appropriately if unavailable for use
- Evaluated through appropriate technical support
- Assessed using manufacturer documentation and approved network resources
- Configured or repaired only by qualified personnel
Potential causes may include network infrastructure, software, interface, or internal communication functions.

## Clinical Use Tip

Ensure clinical documentation processes remain available if electronic data transfer is unavailable.
