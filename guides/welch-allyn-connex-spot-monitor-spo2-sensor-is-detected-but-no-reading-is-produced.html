SpO2 Sensor Is Detected but No Reading Is Produced

Welch Allyn

Connex Spot Monitor

What This Guide Helps With

Troubleshoot detected SpO2 sensors that produce no saturation reading because of sensor condition, cable problems, signal quality, or configuration issues.

Step-by-Step Troubleshooting

1. Ensure Patient Safety and Confirm the Symptom

If oxygen saturation monitoring is unreliable, transfer monitoring to another verified device when clinically required.

Determine whether the monitor recognizes the sensor but displays dashes, a searching indication, an error, or no numerical result.

Expected outcome: The reported failure is identified and appropriate patient monitoring remains available.

2. Inspect the SpO2 Sensor

Examine the sensor for:

  • Damaged cable insulation.
  • Broken or contaminated optical surfaces.
  • Loose connector components.
  • Incorrect sensor type.
  • Visible wear affecting sensor placement.

Confirm the sensor is approved for the installed SpO2 technology and monitor configuration.

Expected outcome: The sensor is compatible, clean, and physically intact.

3. Inspect the Extension Cable and Monitor Connection

Check any installed extension cable and the monitor's accessible SpO2 connector.

Look for bent pins, loose connections, contamination, or cable strain.

Reconnect the components securely without forcing connectors.

Expected outcome: The complete external sensor connection is secure and undamaged.

If correcting a loose connection restores a stable reading, proceed to verification.

4. Check Sensor Placement and Signal Conditions

Verify appropriate sensor placement using a suitable test arrangement or qualified clinical assessment.

Consider conditions that interfere with optical measurement, including motion, poor perfusion, excessive ambient light, or incorrect sensor positioning.

Do not use a questionable patient reading as proof of device accuracy.

Expected outcome: The sensor has suitable signal conditions and no obvious positioning problem.

5. Confirm the Installed SpO2 Technology

Identify the monitor's installed SpO2 option and verify that the sensor and extension cable are compatible.

Do not interchange sensors intended for different SpO2 technologies merely because their connectors appear similar.

Check for any displayed sensor or parameter status messages.

Expected outcome: The monitor and connected accessories form a supported measurement configuration.

6. Test With Known-Good Accessories

Substitute a known-good compatible sensor and, if applicable, extension cable.

Use an approved SpO2 simulator or manufacturer-recommended functional test arrangement.

Compare the results with the original accessories.

Expected outcome: The monitor detects the sensor and produces a stable numerical reading under valid test conditions.

If a replacement accessory resolves the failure, remove the defective accessory from use.

7. Verify SpO2 Display and Measurement Function

Perform the applicable manufacturer-approved functional verification.

Confirm that numerical values, pulse information, signal indicators, and relevant parameter messages behave appropriately.

Recognize that some simulators verify functional response rather than complete clinical accuracy.

Expected outcome: The SpO2 system passes its applicable functional verification.

If the original complaint is resolved and testing passes, troubleshooting can stop.

8. Escalate Unresolved SpO2 Failure

If no valid reading is produced with compatible known-good accessories and an approved test setup, stop external troubleshooting.

Expected outcome: The monitor remains unavailable for affected clinical monitoring until qualified evaluation is complete.

If the Problem Persists

External sensor, cable, compatibility, and signal-quality causes have been ruled out. Possible remaining causes include an internal SpO2 interface problem, parameter electronics fault, software issue, or authorized configuration problem.

Remove the monitor from service, label it Out of Service, and arrange repair or bench evaluation using manufacturer documentation and approved test equipment.

Only qualified personnel should perform repairs or configuration changes. Complete the required SpO2 functional verification before returning the monitor to service.

Knowing when to stop external troubleshooting is proper troubleshooting.

Clinical Use Tip

A displayed SpO2 value must not be treated as reliable when signal quality is poor or inconsistent with the patient's clinical condition.

Work Order Documentation (CCR Method)

CCR = Complaint, Cause, Resolution

Complaint

What was reported by the clinical staff.

Example:
"Clinical staff reported that the Connex Spot Monitor detected the SpO2 sensor but did not display an oxygen saturation value."

Cause

What was observed during troubleshooting.

Example:
"Clinical Engineering found an intermittent connection in the external SpO2 extension cable."

Resolution

What action was taken.

Example:
"Replaced the extension cable with a compatible accessory and verified stable SpO2 operation using approved test equipment."

Helpful Details to Include (If Known)

  • Installed SpO2 technology.
  • Displayed sensor or signal message.
  • Sensor and cable condition.
  • Sensor compatibility.
  • Connector condition.
  • Known-good substitutions.
  • Simulator or functional test results.
  • Final monitor status.

Final Thought

SpO2 troubleshooting requires reliable alternate monitoring, careful accessory inspection, and controlled signal verification. Eliminate external causes before suspecting internal electronics, escalate unresolved faults, and document both the findings and final test results.

That is successful troubleshooting.
