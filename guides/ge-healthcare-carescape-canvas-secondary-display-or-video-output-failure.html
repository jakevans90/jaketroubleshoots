GE Healthcare CARESCAPE Canvas

Secondary Display or Video Output Failure

Asset Type

Patient Monitor

Manufacturer

GE Healthcare

Model

CARESCAPE Canvas

What This Guide Helps With

Troubleshooting a blank, intermittent, distorted, or missing secondary display caused by power, cabling, input selection, configuration, or external display failure.

Step-by-Step Troubleshooting

1. Ensure Patient Safety First

Do not perform extended display troubleshooting while the CARESCAPE Canvas is actively supporting patient care.

If the primary display is also unavailable, unreadable, or unreliable:

  • Notify the clinical team immediately.
  • Transfer monitoring to another verified patient monitor.
  • Confirm that alarms, waveforms, parameter values, and patient identification are visible on the replacement device.
  • Do not rely solely on a remote or secondary display for alarm recognition or clinical decisions.

Expected outcome: Patient monitoring continues without depending on an unreliable display system.

Continue Clinical Engineering troubleshooting only after the affected equipment can be safely evaluated.

2. Confirm Which Display Has Failed

Determine whether the problem affects:

  • Only the secondary display
  • Both the primary and secondary displays
  • The secondary display intermittently
  • The picture only, while the display remains powered
  • A particular screen, room, mounting location, or video connection

Check whether the primary CARESCAPE Canvas display is operating normally and showing live parameters.

Expected outcome: The failure is isolated to the secondary display path or identified as a broader monitor problem.

If the primary display is also blank, frozen, or restarting, stop this procedure and troubleshoot the main monitor power or startup condition instead.

3. Check the Secondary Display’s Power

Verify that:

  • The display power cord is fully seated.
  • The power supply or external adapter is connected, when applicable.
  • The display power indicator is illuminated.
  • The power switch is in the correct position.
  • The connected outlet is functional.

Test the outlet with an approved electrical tester or connect the display to a known-good approved outlet.

Expected outcome: The secondary display powers on and shows a startup logo, status message, or input notification.

If restoring power resolves the issue, verify stable operation and stop.

4. Inspect the External Video Cable

Inspect the video cable from the CARESCAPE Canvas system to the secondary display for:

  • Loose connections
  • Partially inserted connectors
  • Bent or damaged connector pins
  • Damaged locking hardware
  • Cuts, crushing, or sharp bends
  • Excessive tension at the monitor arm or wall mount
  • Contamination or fluid exposure

Disconnect and firmly reconnect both ends when safe. Secure any connector fasteners without overtightening them.

Expected outcome: The connector remains firmly seated and the secondary image returns without interruption.

If reseating the cable resolves the issue, gently move the cable near each connector to confirm the image remains stable, then stop.

5. Verify the Correct Display Input

Use the secondary display’s external controls to confirm that the selected input matches the connected video cable.

Look for messages such as:

  • No Signal
  • Check Cable
  • Unsupported Signal
  • Input Not Found
  • Power Saving Mode

Do not change clinical settings on the CARESCAPE Canvas while checking the external display input.

Expected outcome: The display is set to the correct input and begins showing the monitor image.

If selecting the proper input resolves the issue, confirm the display does not revert after a power cycle and stop.

6. Inspect Adapters, Extenders, and Docking Connections

If the installation uses a video adapter, signal extender, wall plate, docking connection, or other intermediary device:

  • Confirm every connection is fully seated.
  • Verify that any powered extender has power.
  • Check for damaged status indicators or loss-of-link lights.
  • Bypass a removable adapter or extension device when this can be done safely with an approved known-good cable.

Do not substitute unapproved consumer adapters for permanently installed clinical equipment.

Expected outcome: The video path is complete and the image is restored when a defective or disconnected intermediary component is corrected.

If the image returns after bypassing an accessory, remove that accessory from service and stop.

7. Test With a Known-Good Video Cable

Replace the existing external video cable with a compatible, approved known-good cable of the same connection type.

Route the test cable directly when possible to eliminate wall plates, extensions, and cable-management pinch points.

Expected outcome: A stable image appears on the secondary display.

If the known-good cable resolves the issue, replace the defective cable, secure it properly, and stop.

8. Test the Secondary Display Independently

Connect an approved known-good video source to the secondary display when permitted by facility procedures.

Confirm whether the display can produce a stable image using the same input.

Expected outcome: The test determines whether the secondary display itself is functional.

If the display fails with another known-good source, remove the secondary display from service for repair or replacement.

If the display works normally, continue evaluating the CARESCAPE Canvas video-output path.

9. Test the CARESCAPE Canvas Output With a Known-Good Display

Connect the video output to a compatible known-good display using an approved cable.

Do not change resolution, service settings, or system configuration unless authorized by GE HealthCare documentation and facility policy.

Expected outcome: The test isolates the failure to either the original display or the monitor’s video-output path.

If the known-good display works, replace or repair the original secondary display.

If the known-good display also shows no image, continue to the next step.

10. Verify the Installed Configuration

Confirm that the secondary-display function is part of the device’s approved installed configuration and was previously operational.

Review:

  • Equipment configuration records
  • Installation documentation
  • Recent software or configuration changes
  • Monitor replacement history
  • Room renovation or cable-routing work
  • Whether the failure began after service, relocation, or an update

CARESCAPE Canvas is a configurable monitoring platform, so available connections and display behavior may depend on the installed hardware and system configuration.

Expected outcome: The secondary display is confirmed as an approved feature and no unauthorized configuration change is identified.

If the installation was recently changed, restore the last verified configuration only when authorized and documented.

11. Perform a Controlled Restart

After ensuring the monitor is not supporting an active patient, perform a normal controlled shutdown and restart according to facility procedures.

Avoid repeated rapid power cycling.

Observe whether:

  • The primary display starts normally.
  • The secondary display shows startup activity.
  • The video signal appears only after the operating interface loads.
  • Any error or configuration message appears.
  • The image disappears again after startup.

Expected outcome: A temporary communication or startup condition clears and both displays remain stable.

If the secondary display returns, operate the system long enough to verify the image remains stable before returning it to service.

12. Complete a Functional Verification

Before returning the system to clinical use:

  • Confirm the primary display remains normal.
  • Confirm the secondary image is stable and readable.
  • Verify displayed patient information matches the primary display.
  • Check that waveforms and parameter values update normally.
  • Verify there is no flickering, distortion, color loss, or intermittent blanking.
  • Confirm cables are secured without strain.
  • Perform any required post-service operational and electrical safety checks.

The secondary display must not obscure, delay, or incorrectly represent patient-monitoring information.

Expected outcome: The complete display system operates reliably and passes the facility’s return-to-service requirements.

If the Problem Persists

If power, input selection, cables, adapters, external display operation, approved configuration, and controlled restart have been checked, the common external causes have been ruled out.

The failure may involve the CARESCAPE Canvas video-output hardware, internal communication, software configuration, or another component requiring authorized service.

The device should be:

  • Removed from service
  • Labeled Out of Service
  • Sent for repair or bench evaluation
  • Escalated to GE HealthCare or an authorized service provider when required

Do not open the monitor, replace internal boards, or alter service-level settings without appropriate authorization, documentation, training, and service information.

Knowing when to stop after isolating the failure is proper troubleshooting.

Clinical Use Tip

A secondary display should be treated as supplemental unless the installed clinical workflow specifically designates otherwise. Never troubleshoot display hardware while it is required for active patient monitoring. Move the patient to another verified monitoring system first.

Work Order Documentation (CCR Method)

CCR = Complaint, Cause, Resolution

Complaint

What was reported by the clinical staff.

Example:
"Clinical staff reported that the CARESCAPE Canvas primary screen was operating, but the connected secondary display remained blank and showed “No Signal.”"

Cause

What was observed during troubleshooting.

Example:
"Clinical Engineering found that the video cable at the secondary display was loose and intermittently lost connection when the monitor arm was repositioned."

Resolution

What action was taken.

Example:
"Reseated and secured the video cable, verified a stable image on both displays, completed functional testing, and returned the monitor to service."

Helpful Details to Include (If Known)

  • Primary display status
  • Secondary display power indicator
  • Message shown on the secondary display
  • Selected video input
  • Outlet tested
  • Video cable inspected or swapped
  • Adapters or extenders bypassed
  • Known-good display test result
  • Known-good video source test result
  • Whether the issue followed relocation or service
  • Software or configuration changes
  • Flickering, distortion, or intermittent behavior
  • Unusual heat, sound, or odor
  • Controlled restart result
  • Final device status

Final Thought

Secondary-display failures should be isolated logically by checking patient safety, external power, input selection, cabling, adapters, and the display before suspecting the monitor’s internal video-output system. Clear CCR documentation preserves the evidence supporting repair, replacement, or safe return to service.

That is successful troubleshooting.
