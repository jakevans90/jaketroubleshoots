Welch Allyn SureTemp Plus 692

Configuration, Units, or Default Settings Will Not Save

Asset Type

Thermometer

Manufacturer

Welch Allyn

Model

SureTemp Plus 692

What This Guide Helps With

Troubleshoots settings that revert or fail to save due to controls, battery power, workflow, approved configuration, or internal memory faults.

Step-by-Step Troubleshooting

1. Protect the Patient and Prevent Use With Incorrect Settings

Do not return the thermometer to clinical use when units, measurement mode, or defaults may change unexpectedly. Provide another verified thermometer and clearly identify the affected device.

Expected outcome: Staff do not take measurements using uncertain units or configuration.

2. Confirm Which Setting Does Not Save

Ask staff which setting was changed, what value was expected, what value returned, and when it reverted. Determine whether the issue follows power-off, battery replacement, probe storage, or a completed measurement.

Record the current displayed units and mode before making any changes.

Expected outcome: The exact setting and trigger for reversion are identified.

3. Verify the Requested Setting Is Authorized

Confirm the requested units, defaults, and operating modes match facility policy and the approved device configuration. Do not change protected settings simply to satisfy an individual preference.

Expected outcome: The intended configuration is authorized and appropriate for the clinical area.

4. Verify the Normal Setting Procedure

Use the approved user-level or service-level procedure appropriate to Clinical Engineering. Complete the entire save or exit sequence and allow the thermometer to return to normal operation before powering it off.

Do not use undocumented button combinations or unauthorized menus.

Expected outcome: The setting is entered and saved using the correct procedure. If it remains after restart, troubleshooting can stop after verification.

5. Check Keypad and Mode-Button Response

Confirm every button required for changing and saving the setting responds reliably. Inspect for contamination, sticking, a damaged overlay, or liquid intrusion.

Expected outcome: The control sequence is accepted without missed or repeated button presses.

6. Verify Battery Condition

Install a fresh matched set of correct batteries and inspect the contacts. Weak or interrupted power during configuration may prevent settings from being stored.

Expected outcome: The thermometer has stable power throughout configuration and restart.

7. Save One Setting at a Time

Change only one approved setting, complete the proper save sequence, restart the thermometer, and confirm whether that individual setting remains.

This helps identify whether the issue affects all configuration memory or one specific option.

Expected outcome: The selected setting remains after restart. If it does, repeat with other authorized settings as needed.

8. Check Whether Battery Removal Causes Reversion

Record the setting, power the device off normally, restart it, and confirm retention. If appropriate under the approved procedure, then remove and reinstall the batteries and check again.

Do not assume all settings are intended to persist through every type of power interruption; verify expected behavior in manufacturer documentation.

Expected outcome: Setting retention matches documented behavior.

9. Compare With a Verified Thermometer

Compare the configuration process and retention behavior with another SureTemp Plus 692 from the same facility and clinical area.

Do not copy settings that are not approved for the affected unit.

Expected outcome: The suspect thermometer either behaves normally or is confirmed to have abnormal retention.

10. Confirm Units and Indicators After Measurement

Using an approved simulator or verification method, complete a measurement and confirm that the displayed units, mode, and default behavior remain correct before, during, and after the cycle.

Expected outcome: The approved configuration remains stable through normal operation.

11. Escalate Unauthorized or Unavailable Configuration Changes

If the requested setting requires a restricted service procedure, configuration tool, or protected access, stop and follow the facility’s authorized escalation process.

Expected outcome: Configuration is performed only by qualified personnel using approved documentation.

12. Remove the Device From Service if Settings Revert

If authorized settings continue to revert despite correct procedure, responsive controls, and fresh batteries, remove the thermometer from service.

Expected outcome: A device with unreliable units or defaults is not returned to clinical use.

If the Problem Persists

External causes involving user workflow, control response, battery power, and approved configuration have been ruled out. The remaining problem may involve nonvolatile memory, internal power interruption, control circuitry, corrupted configuration data, or another service-level issue.

Remove the thermometer from service, label it Out of Service, and send it for repair or bench evaluation. Use appropriate Welch Allyn service documentation and approved tools. Protected configuration and internal repair should be performed only by qualified personnel.

Before return to service, verify all authorized settings, power-cycle retention, units, operating modes, repeated measurements, and temperature accuracy. Knowing when to stop external troubleshooting is proper troubleshooting.

Clinical Use Tip

Verify the displayed temperature units and measurement mode before every clinical use when a device has recently undergone battery replacement, configuration, or repair.

Work Order Documentation (CCR Method)

CCR = Complaint, Cause, Resolution

Complaint

What was reported by the clinical staff.

Example:
"Clinical staff reported that the SureTemp Plus 692 returned to the previous temperature units after being powered off."

Cause

What was observed during troubleshooting.

Example:
"Clinical Engineering found that the setting-change sequence had been exited before the save step was completed."

Resolution

What action was taken.

Example:
"Clinical Engineering entered the approved units setting, completed the required save sequence, and verified retention after repeated power cycles and measurements."

Helpful Details to Include (If Known)

  • Setting or units requested
  • Previous and desired values
  • When the setting reverts
  • Approved facility configuration
  • Button-response findings
  • Battery and contact condition
  • Save procedure used
  • Power-cycle retention result
  • Comparison-unit behavior
  • Measurement verification result
  • Final device status

Final Thought

Treat unstable units and defaults as a patient-safety issue. Confirm authorization, correct procedure, responsive controls, and stable power before suspecting memory failure, then escalate appropriately and document the retained final configuration.

That is successful troubleshooting.
