Syringe Pump Not Recognized or Syringe Delivery Failure

Asset Type

Continuous Renal Replacement Therapy (CRRT)

Manufacturer

Vantive

Model

PrisMax

What This Guide Helps With

Helps troubleshoot syringe pump issues related to syringe installation, connections, settings, or external setup.

Step-by-Step Troubleshooting

1. Confirm patient safety

Ensure patient therapy and medication delivery needs are addressed before troubleshooting. Expected outcome: Patient safety is maintained.

2. Confirm the syringe pump issue

Verify whether the issue is recognition, delivery, or interruption. Expected outcome: Correct condition is identified.

3. Inspect syringe installation and external components

Verify the syringe is properly installed and visible external components are correctly positioned. Expected outcome: Syringe setup is correct.

4. Inspect connections and tubing

Check visible syringe tubing and connections for restrictions, disconnections, or damage. Expected outcome: External delivery path is intact.

5. Verify configuration and settings

Confirm the appropriate syringe-related settings and selections are present according to approved clinical use. Expected outcome: Configuration matches intended operation.

6. Perform final verification

Verify syringe recognition and delivery operation. Expected outcome: Syringe function is restored and troubleshooting can stop.

If the Problem Persists

External setup, connections, and configuration issues have been ruled out. The device should be:

  • Removed from service
  • Labeled Out of Service
  • Sent for repair or bench evaluation
  • Evaluated using approved documentation and test equipment
  • Repaired only by qualified personnel

Clinical Use Tip

Verify alternate medication delivery if syringe delivery cannot be confirmed.

Work Order Documentation (CCR Method)

CCR = Complaint, Cause, Resolution

Complaint

What was reported by the clinical staff.

Example:
"Clinical staff reported the PrisMax syringe pump was not recognized during treatment."

Cause

What was observed during troubleshooting.

Example:
"Clinical Engineering found the syringe was not properly seated in the external holder."

Resolution

What action was taken.

Example:
"Clinical Engineering corrected syringe placement and verified normal operation."

Helpful Details to Include (If Known)

  • Alarm message
  • Syringe type
  • Installation condition
  • Tubing inspection
  • Settings observed
  • Final delivery verification

Final Thought

CRRT troubleshooting depends on safe patient management, external verification, and proper escalation. Documentation confirms the corrective action and final status. That is successful troubleshooting.
