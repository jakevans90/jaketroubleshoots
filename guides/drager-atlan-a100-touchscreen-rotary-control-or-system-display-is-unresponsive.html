Touchscreen, Rotary Control, or System Display Is Unresponsive

Asset Type

Anesthesia Machine

Manufacturer

Drager

Model

Atlan A100

What This Guide Helps With

Addresses unresponsive controls or display behavior caused by startup state, external obstruction, contamination, power issues, attached accessories, or control-system faults.

Step-by-Step Troubleshooting

1. Protect the Patient and Stop Clinical Dependence

Do not troubleshoot frozen controls or an unreliable display while the machine is supporting a patient. Transfer ventilation and anesthesia to another verified system.

If settings cannot be viewed or changed reliably, remove the machine from service.

Expected outcome: Patient care no longer depends on the affected user interface.

2. Confirm What Is Unresponsive

Determine whether the touchscreen alone is affected, the rotary control alone is affected, all controls are frozen, the display is blank, or the screen image remains visible but no input is accepted.

Record whether alarms and ventilation appeared to continue when the issue occurred.

Expected outcome: The failure is clearly characterized and reproducible if safe to do so.

3. Verify AC Power and Startup State

Confirm stable AC power and inspect the power cord, inlet, plug, and visible power indications.

Observe whether the machine is still starting, completing a system test, or displaying a condition that temporarily limits input.

Expected outcome: The machine has stable power and has completed normal startup. Correct any external power issue before proceeding.

4. Inspect the Touchscreen Surface

Check for heavy contamination, liquid, adhesive covers, drapes, objects pressing on the screen, or other material that could interfere with touch operation.

Clean only according to approved methods.

Expected outcome: The touchscreen surface is clean, dry, and unobstructed. If normal response returns, continue functional testing.

5. Inspect the Rotary Control and External Controls

Verify the rotary control is not mechanically jammed, damaged, or blocked by accessories. Check other user-accessible keys for normal physical movement.

Do not force a stuck control.

Expected outcome: Controls move normally without visible mechanical damage.

6. Disconnect Nonessential External Accessories

Remove nonessential externally connected accessories or data connections that can safely be excluded from a bench test.

This can help identify an attached accessory causing abnormal startup or interface behavior.

Expected outcome: The machine operates normally without optional external accessories, or the user-interface failure remains unchanged.

7. Perform a Controlled Restart

With the machine out of patient use, perform a normal shutdown and restart using standard controls.

Do not repeatedly interrupt power or access unauthorized service functions.

Expected outcome: The display and controls initialize and respond normally after restart. If so, continue to a complete system test before considering return to service.

8. Observe for Recurrence During the System Test

Run the normal system test and operate the touchscreen and rotary control through standard user-accessible functions.

Check for intermittent freezing, delayed response, display artifacts, or unexpected rebooting.

Expected outcome: Controls remain responsive throughout the test. If the failure recurs, remove the unit from service.

9. Perform Final Functional Verification

Verify the ability to select settings, acknowledge alarms, navigate required screens, and observe ventilation parameters. Confirm normal display operation, alarms, and system-test completion.

Expected outcome: All user controls and displayed information remain reliable. Troubleshooting can stop.

10. Escalate Persistent or Intermittent Interface Failure

If the display or controls remain unresponsive or the problem returns during testing, do not return the machine to clinical use even if a restart temporarily restores operation.

Expected outcome: The machine is removed from service for qualified evaluation of the display, control interface, power subsystem, or associated electronics.

If the Problem Persists

External power, contamination, control obstruction, accessory interaction, and startup state have been ruled out. Persistent or intermittent failures may involve the display assembly, touchscreen interface, rotary-control hardware, internal communication, power electronics, or system software requiring service-level diagnosis.

The device should be:

  • Removed from service.
  • Labeled Out of Service.
  • Sent for repair or bench evaluation.
  • Evaluated using appropriate Drager documentation and approved test equipment.
  • Repaired or configured only by qualified personnel.
  • Fully tested through normal startup, system test, control operation, alarms, and ventilation verification before return to service.

A control that works only after repeated restarting should not be considered reliably repaired.

Clinical Use Tip

If clinicians cannot reliably view or change anesthesia settings, move the patient to another verified machine before troubleshooting the interface.

Work Order Documentation (CCR Method)

CCR = Complaint, Cause, Resolution

Complaint

What was reported by the clinical staff.

Example:
"OR staff reported that the touchscreen on the Drager Atlan A100 stopped responding while the rotary control remained functional."

Cause

What was observed during troubleshooting.

Example:
"Clinical Engineering found moisture and cleaning residue on the touchscreen surface interfering with touch input."

Resolution

What action was taken.

Example:
"Clinical Engineering cleaned and dried the touchscreen using the approved method, restarted the machine, verified normal touchscreen and rotary-control operation throughout the system test, and returned the machine to service."

Helpful Details to Include (If Known)

  • Touchscreen, rotary control, or entire display affected
  • Blank, frozen, delayed, or distorted display
  • AC or battery status
  • Alarm and ventilation behavior during failure
  • Surface contamination or moisture
  • External accessories connected
  • Whether restart restored operation
  • Whether failure recurred during testing
  • Final system-test result
  • Final device status

Final Thought

Unresponsive anesthesia controls require conservative handling. Verify power, physical condition, contamination, accessories, and restart behavior before assuming internal failure, and remove the machine from service whenever control reliability cannot be demonstrated.

That is successful troubleshooting.
