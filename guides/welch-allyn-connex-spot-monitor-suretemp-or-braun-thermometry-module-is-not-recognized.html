Welch Allyn Connex Spot Monitor

SureTemp or Braun Thermometry Module Is Not Recognized

Asset Type

Vital Signs Monitor

Manufacturer

Welch Allyn

Model

Connex Spot Monitor

What This Guide Helps With

Troubleshoot missing or unrecognized temperature functionality caused by probe, accessory, connection, module compatibility, or configuration problems.

Step-by-Step Troubleshooting

1. Ensure Patient Safety and Identify the Temperature Configuration

If the monitor cannot obtain reliable temperature readings, provide another verified thermometer.

Determine whether the device uses a supported SureTemp temperature system or a compatible Braun thermometry configuration.

Ask staff whether the temperature function is missing, the probe is not detected, or the system displays an error.

Expected outcome: The installed temperature configuration and reported failure are identified without compromising patient assessment.

2. Inspect the Temperature Probe or Thermometer

Check the accessible temperature accessories for:

  • Cracked or damaged probe housing.
  • Bent, contaminated, or damaged contacts.
  • Frayed or pinched cables, where applicable.
  • Incorrect or incompatible probe accessories.
  • Visible damage to the thermometer or holder.

Do not use a damaged probe for patient measurements.

Expected outcome: The installed temperature accessories are physically intact and compatible.

3. Check the Probe Well or Thermometer Dock

For a SureTemp configuration, inspect the accessible probe well, probe seating, and external connections.

For a compatible Braun configuration, inspect the thermometer holder, accessible contacts, and docking arrangement.

Remove visible contamination using manufacturer-approved cleaning methods.

Expected outcome: The probe or thermometer seats correctly and the accessible connection surfaces are clean and undamaged.

4. Verify Installed Module Recognition

Check whether the monitor displays the temperature parameter or a module-related status message.

Confirm that the installed temperature option is supported by the specific monitor configuration.

Do not assume every Connex Spot Monitor supports both temperature technologies interchangeably.

Expected outcome: The monitor recognizes its installed and supported temperature configuration.

5. Check Power and Startup Behavior

Confirm that the monitor starts normally and other installed vital signs functions are available.

With the device removed from clinical use, perform an approved restart if appropriate.

Observe whether the temperature function appears during startup and remains available afterward.

Expected outcome: The temperature function initializes without an unexplained error.

If normal recognition returns and remains stable, continue to verification.

6. Substitute Known-Good Compatible Accessories

Where supported, test with a known-good probe, probe well, thermometer, or approved external accessory.

Do not interchange incompatible SureTemp and Braun components.

Compare the monitor's behavior before and after substitution.

Expected outcome: A functioning compatible accessory is recognized consistently.

If replacing an external accessory resolves the issue, remove the defective accessory from use.

7. Verify Temperature Measurement Performance

Use an approved temperature verification device or manufacturer-specified test method suitable for the installed technology.

Check that the monitor obtains and displays a stable temperature result within applicable specifications.

Expected outcome: Temperature measurement and display functions pass the required verification.

If recognition and measurement performance are correct, troubleshooting can stop.

8. Escalate Persistent Module Recognition Failure

If the supported temperature system remains unavailable after external checks, document the observed condition and stop.

Expected outcome: The device is held from affected clinical use pending qualified evaluation.

If the Problem Persists

External accessory, connection, seating, and startup causes have been ruled out. Possible remaining categories include temperature interface faults, internal module problems, firmware incompatibility, or authorized configuration issues.

Remove the monitor from service, label it Out of Service, and send it for repair or bench evaluation. Qualified personnel should evaluate the device using manufacturer documentation and approved test equipment.

Perform temperature function verification and any other applicable return-to-service tests before clinical release.

Knowing when to stop external troubleshooting is proper troubleshooting.

Clinical Use Tip

Do not substitute a different temperature technology without confirming that the clinical workflow and installed monitor configuration support it.

Work Order Documentation (CCR Method)

CCR = Complaint, Cause, Resolution

Complaint

What was reported by the clinical staff.

Example:
"Clinical staff reported that the Connex Spot Monitor would not recognize its SureTemp temperature probe."

Cause

What was observed during troubleshooting.

Example:
"Clinical Engineering identified a damaged external SureTemp probe connection that prevented reliable detection."

Resolution

What action was taken.

Example:
"Replaced the compatible probe assembly and verified recognition and temperature measurement using the approved test method."

Helpful Details to Include (If Known)

  • Installed temperature technology.
  • Exact displayed error or missing parameter.
  • Probe, holder, and connection condition.
  • Accessory compatibility.
  • Recognition behavior during startup.
  • Known-good substitutions.
  • Temperature verification results.
  • Final device status.

Final Thought

Temperature module troubleshooting begins with patient safety and verification of the installed technology. Inspect accessible accessories and connections before assuming internal failure, confirm measurement performance, escalate persistent problems, and document the corrective action.

That is successful troubleshooting.
