Automatic Scope Leak Test Fails With a Known-Good Scope

Asset Type

Endoscope Reprocessor (AER)

Manufacturer

Olympus

Model

OER-Pro

What This Guide Helps With

Troubleshoots repeated automatic leak-test failures caused by connections, adapters, scope setup, moisture, positioning, or other external leak-test path problems.

Step-by-Step Troubleshooting

1. Protect Patient Safety and Reprocessing Continuity

Do not release an endoscope for patient use when the required leak-test or reprocessing cycle has not been successfully completed. Remove the affected OER-Pro from clinical workflow if reliable leak testing cannot be confirmed.

Move processing to another verified reprocessor or approved alternate workflow according to facility policy. Do not continue repeatedly cycling scopes while the cause remains unknown.

Expected outcome: Endoscope reprocessing continues through a verified method while the affected equipment is evaluated.

If another verified reprocessor completes the required leak test successfully, continue troubleshooting the OER-Pro without risking an improperly processed scope.

2. Confirm the Exact Reported Failure

Determine whether the leak test fails:

  • With one endoscope or multiple scopes
  • Every cycle or intermittently
  • Immediately after connection or later during testing
  • With a specific scope family, connector, or adapter
  • After cleaning, maintenance, or replacement of an accessory

Record the exact displayed message or indication without interpreting it as an internal failure.

Expected outcome: The failure pattern is clearly established.

If the problem occurs only with one scope or accessory, remove that item from use and troubleshoot it separately rather than assuming an OER-Pro malfunction.

3. Verify the Known-Good Scope Independently

Confirm that the scope being used for comparison has successfully passed the appropriate leak test using another verified method or reprocessor.

Inspect the scope externally for obvious damage, moisture at connectors, loose fittings, or contamination that could affect the test.

Expected outcome: The comparison scope is confirmed suitable for testing.

If the scope does not pass an independent leak test, the issue is not proven to be with the OER-Pro. Stop troubleshooting the reprocessor and address the scope.

4. Inspect the Leak-Test Connection and Adapter

Inspect the OER-Pro leak-test connection, scope connector, adapter, and associated tubing for:

  • Loose or incomplete connection
  • Bent, damaged, or contaminated fittings
  • Cracked tubing
  • Pinched tubing
  • Moisture or debris
  • Incorrect adapter selection
  • Excessive strain on the connection

Disconnect and reconnect all external leak-test components according to the approved setup.

Expected outcome: All leak-test components are clean, dry, undamaged, correctly matched, and fully seated.

If reseating the connection allows the leak test to complete successfully, troubleshooting can stop after final verification.

5. Verify Scope and Tubing Positioning

Confirm that the scope, connecting tubing, and adapters are positioned without kinks, sharp bends, compression, or tension.

Ensure the scope is loaded in a manner that does not pull against the leak-test fitting when the chamber or lid is secured.

Expected outcome: The entire external leak-test path remains unrestricted and secure throughout setup.

If repositioning eliminates the leak-test failure, repeat verification and return the system to service if all required checks pass.

6. Check for Moisture or Contamination at Connections

Inspect accessible connection points for residual water, detergent, disinfectant, or debris.

Dry and clean external mating surfaces using approved methods. Do not introduce tools, compressed air, or cleaning agents into connections unless specifically permitted by Olympus documentation.

Expected outcome: Leak-test mating surfaces are clean and dry.

If contamination or moisture was preventing a reliable connection and the test now passes repeatedly, troubleshooting can stop.

7. Compare With a Known-Good External Adapter or Connection Set

If compatible equipment is available, substitute a known-good leak-test adapter, connector, or external tubing assembly approved for the OER-Pro.

Change one component at a time so the cause can be identified.

Expected outcome: The leak test completes normally with known-good external components.

If substitution corrects the problem, replace the defective external accessory and perform final functional verification.

8. Verify Normal OER-Pro Setup and Controls

Confirm that the correct processing setup has been selected and that the system is not being operated with an incompatible scope configuration or accessory selection.

Do not enter restricted service menus or alter calibration or manufacturer-level configuration.

Expected outcome: The selected setup matches the connected scope and approved accessories.

If correcting the setup resolves the leak-test failure, repeat the test and stop troubleshooting after successful verification.

9. Test More Than One Verified Scope

When available, test a second independently verified compatible scope using the same OER-Pro.

Compare results while keeping the external accessories controlled.

Expected outcome: Multiple known-good scopes complete the automatic leak test successfully.

If only one scope fails, remove that scope from service. If multiple verified scopes fail on the OER-Pro, the reprocessor requires further evaluation.

10. Perform Final Functional Verification

After correcting an external cause, perform an appropriate complete functional check using approved accessories and facility procedures.

Verify that:

  • The scope is recognized correctly
  • The leak-test connection remains secure
  • The automatic leak test completes successfully
  • No new alarms or abnormal behavior occurs
  • Subsequent processing can proceed normally

Expected outcome: The OER-Pro repeatedly performs the leak test normally with a verified scope.

If successful, document the correction and return the reprocessor to service.

11. Escalate if the Failure Persists

If multiple known-good scopes and known-good external connections still fail the automatic leak test, stop external troubleshooting.

Do not attempt internal pneumatic, sensor, valve, tubing, control-board, or calibration repair without appropriate service documentation and authorization.

Expected outcome: The device is removed from use before unreliable leak testing affects endoscope reprocessing.

If the Problem Persists

Common external causes such as scope condition, adapters, connections, tubing position, moisture, setup, and accessory compatibility have been ruled out.

The remaining cause may involve an internal pneumatic path, pressure sensing, valve operation, configuration, calibration, or another service-level condition.

The OER-Pro should be:

  • Removed from service
  • Labeled Out of Service
  • Sent for repair or bench evaluation
  • Evaluated using appropriate Olympus documentation and approved test equipment
  • Repaired or configured only by qualified personnel

After repair, complete required functional and return-to-service testing before the reprocessor is released for clinical use.

Knowing when to stop external troubleshooting is proper troubleshooting.

Clinical Use Tip

Never treat a failed automatic leak test as a nuisance alarm; ensure the endoscope passes the required leak test before continuing reprocessing or clinical use.

Work Order Documentation (CCR Method)

CCR = Complaint, Cause, Resolution

Complaint

What was reported by the clinical staff.

Example:
"Sterile Processing reported that the OER-Pro repeatedly failed the automatic leak test with a scope known to pass on another reprocessor."

Cause

What was observed during troubleshooting.

Example:
"Clinical Engineering found the external leak-test adapter connection was not fully seated and lost pressure during testing."

Resolution

What action was taken.

Example:
"Reseated and inspected the adapter connection, repeated leak testing successfully with the known-good scope, and verified normal reprocessor operation before return to service."

Helpful Details to Include (If Known)

  • Exact leak-test message or indication
  • Scope model or type tested
  • Whether the scope passed an independent leak test
  • Adapter and tubing condition
  • Connection condition before correction
  • Presence of moisture or contamination
  • Known-good accessories substituted
  • Number of scopes tested
  • Whether failure was intermittent or repeatable
  • Results before and after correction
  • Final device status

Final Thought

Protect the patient by preventing use of an inadequately tested scope, verify the complete external leak-test path before assuming an internal failure, escalate persistent failures appropriately, and document exactly what was found and verified.

That is successful troubleshooting.
