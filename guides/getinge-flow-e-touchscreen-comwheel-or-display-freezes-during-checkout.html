Getinge Flow-e

Touchscreen, ComWheel, or Display Freezes During Checkout

Asset Type

Anesthesia Machine

Manufacturer

Getinge

Model

Flow-e

What This Guide Helps With

The user interface freezes, ignores input, or stops progressing during checkout because of controls, startup state, accessories, software, power, or service-level faults.

Step-by-Step Troubleshooting

1. Protect the Patient and Remove an Unreliable Interface From Clinical Use

Do not troubleshoot frozen or unreliable controls while a patient depends on the Flow-e. An anesthesia machine with an unresponsive interface cannot be assumed safe for continued clinical operation.

Move patient care to a verified alternative system.

Expected outcome: The affected machine is isolated from patient care.

2. Confirm Which Interface Function Failed

Determine whether the touchscreen, ComWheel, physical controls, display image, or entire system stopped responding.

Document the checkout stage at which the freeze occurred and whether values on the screen continued changing.

Expected outcome: The failure is characterized as a localized input problem or broader system freeze.

3. Inspect the Touchscreen Surface

Check for fluid, cleaning residue, adhesive film, gloves or objects resting against the screen, cracked glass, or other conditions that could produce false or blocked touch input.

Clean only according to approved procedures.

Expected outcome: The screen surface is clean, dry, undamaged, and free from unintended contact.

4. Check the ComWheel and External Controls

Verify the ComWheel and accessible controls move normally and are not mechanically jammed, contaminated, or obstructed.

Expected outcome: Physical controls operate freely. If restoring normal movement resolves the issue, repeat checkout.

5. Remove Nonessential External Accessories

Disconnect nonessential externally connected accessories or data peripherals that can safely be removed for testing.

Do not disconnect required internal assemblies or open the machine.

Expected outcome: The system can be tested in a simplified configuration. If the freeze disappears after one external accessory is removed, isolate that accessory and verify operation.

6. Verify Stable AC Power

Confirm the machine is connected to a known-good receptacle and inspect the power cord for intermittent connection or damage.

Expected outcome: Power remains stable during checkout. Correct any external power problem and repeat testing.

7. Perform a Controlled Restart

With the machine removed from patient use, perform a normal shutdown and restart using the approved operating method.

Do not force power interruption unless directed by authorized service documentation.

Expected outcome: The machine completes startup and the touchscreen, ComWheel, and display respond normally.

8. Reproduce the Failure During Checkout

Run checkout again and observe whether the interface freezes at the same stage or during the same function.

Document the sequence before the failure.

Expected outcome: Checkout completes without freezing. If the failure is reproducible, escalation is warranted even if a restart temporarily clears it.

9. Verify All User Controls Before Return to Service

Test touchscreen response across normal accessible control areas, verify ComWheel navigation and confirmation, and confirm display information updates normally.

Then complete the full anesthesia-machine checkout.

Expected outcome: All controls respond consistently and checkout completes successfully. Intermittent controls are not acceptable for return to service.

10. Escalate Recurrent or Unexplained Freezing

If the interface freezes again, reboots unexpectedly, loses display information, or becomes intermittently unresponsive after basic external checks, stop troubleshooting.

Expected outcome: The machine remains out of service for qualified service evaluation.

If the Problem Persists

External screen contamination, control obstruction, accessories, and AC-power problems have been ruled out. Remaining possibilities include internal display or control hardware, communications faults, software instability, internal power problems, or service-level configuration.

The device should be:

  • Removed from service.
  • Labeled Out of Service.
  • Sent for repair or bench evaluation.
  • Evaluated using approved Getinge service documentation and diagnostic procedures.
  • Repaired or software-configured only by qualified personnel.

Do not return a machine to service because a reboot temporarily cleared a recurring control freeze.

Final return-to-service testing should include complete checkout, verification of all user controls, alarms, ventilation, gas delivery, and applicable electrical-safety testing.

Clinical Use Tip

An intermittent control interface is a patient-safety problem even when ventilation or gas delivery appears normal at the moment.

Work Order Documentation (CCR Method)

CCR = Complaint, Cause, Resolution

Complaint

What was reported by the clinical staff.

Example:
"Anesthesia staff reported that the Flow-e touchscreen stopped responding midway through checkout while the display remained powered."

Cause

What was observed during troubleshooting.

Example:
"Clinical Engineering found dried cleaning residue along the touchscreen edge causing unreliable touch response."

Resolution

What action was taken.

Example:
"Cleaned the touchscreen according to approved procedures, verified touchscreen and ComWheel operation, completed checkout without recurrence, and returned the machine to service."

Helpful Details to Include (If Known)

  • Touchscreen, ComWheel, display, or entire system affected
  • Checkout stage when freeze occurred
  • Whether values continued updating
  • Screen contamination or damage
  • External accessories connected
  • AC source tested
  • Restart result
  • Recurrence after restart
  • Full checkout result
  • Final device status

Final Thought

Treat unreliable controls as a safety issue, eliminate simple external and power-related causes first, verify the problem does not recur during full checkout, and escalate intermittent freezes rather than accepting a temporary reset.

That is successful troubleshooting.
