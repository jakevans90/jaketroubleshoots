Mindray WATO EX Series

CO2 or Agent Gas Module Not Recognized

Asset Type

Anesthesia Machine

Manufacturer

Mindray

Model

WATO EX Series

What This Guide Helps With

Troubleshooting an unrecognized CO2 or multi-gas module caused by installation, connection, compatibility, contamination, startup, or external module failure.

Step-by-Step Troubleshooting

1. Ensure Patient Safety First

Do not remove, exchange, or restart a gas module while the anesthesia machine is supporting an active patient.

If CO2 or anesthetic-agent monitoring becomes unavailable during a procedure:

  • Notify the anesthesia provider immediately.
  • Confirm ventilation and anesthetic delivery using approved independent monitoring.
  • Maintain continuous oxygen saturation, airway-pressure, and ventilation assessment.
  • Move the patient to another verified anesthesia machine when required monitoring cannot be maintained safely.

Expected outcome: Patient care no longer depends on an anesthesia machine with unavailable respiratory-gas monitoring.

Continue troubleshooting only after the WATO EX Series machine is safely removed from patient use.

2. Confirm the Exact Failure

Record the complete displayed message and determine whether:

  • The module is not detected at all.
  • The module appears but CO2 or agent values are unavailable.
  • Recognition is intermittent.
  • The problem began after the module was removed, cleaned, exchanged, or relocated.
  • The failure affects only CO2 or all measured gases.

Expected outcome: The issue is identified as a recognition failure rather than a sampling or measurement failure.

If the module is recognized but displays no gas values, inspect the sampling line, water trap, exhaust connection, and sampling conditions instead of treating it as a recognition problem.

3. Inspect the Module Installation

With the machine out of service:

  • Remove the module according to approved facility practices.
  • Inspect the module housing and module bay for damage, contamination, or foreign material.
  • Confirm that no labels, tape, covers, or accessories interfere with insertion.
  • Reinsert the module evenly until it is fully seated and mechanically secure.

Do not force the module into the bay.

Expected outcome: The module sits flush, remains secure, and is detected by the anesthesia machine.

If recognition returns, complete an operational checkout and stop troubleshooting.

4. Verify Module Compatibility

Confirm that the installed CO2 or multi-gas module is approved for the specific WATO EX model and software configuration.

The WATO EX family supports optional CO2 and plug-and-play multi-gas monitoring, but compatible module types and available functions may differ by model and configuration.

Check:

  • Module model and part number
  • Intended host-device compatibility
  • Facility inventory or configuration records
  • Whether the module was recently moved from another monitor or anesthesia machine

Expected outcome: An approved and compatible module is installed.

If the module is incompatible, replace it with the correct approved module and stop troubleshooting.

5. Check the Module’s External Condition

Inspect for:

  • Cracked or distorted housing
  • Bent, recessed, contaminated, or damaged connector contacts
  • Evidence of fluid intrusion
  • Unusual heat
  • Burnt odor
  • Loose internal components indicated by rattling

Do not use compressed air, liquids, metal tools, or abrasive materials on electrical contacts.

Expected outcome: The module and connector surfaces are clean, dry, undamaged, and safe to test.

Remove a damaged or fluid-contaminated module from service.

6. Inspect Sampling Accessories

Although sampling accessories normally do not control module recognition, an improperly installed accessory may be reported as “module unavailable” or mistaken for a recognition failure.

Confirm that:

  • The correct water trap is installed.
  • The water trap is fully seated.
  • The sampling line is connected to the correct inlet.
  • The sampling line is not kinked, blocked, saturated, or damaged.
  • The exhaust connection is unobstructed when applicable.
  • No liquid is visible inside the sampling inlet.

Expected outcome: Sampling accessories are correctly installed and unobstructed.

If the module becomes operational, allow the required warm-up period and verify stable readings with an approved gas source or analyzer.

7. Restart the System Safely

With the machine disconnected from patient use:

  • Shut down the WATO EX Series normally.
  • Remove and reseat the module.
  • Restore power and allow the system to complete its startup sequence.
  • Observe whether the module appears in the monitoring setup.
  • Allow sufficient module warm-up before evaluating measurement availability.

Expected outcome: The machine recognizes and initializes the module without recurring messages.

If recognition returns, complete the manufacturer-required pre-use checkout and verify CO2 or agent measurement before release.

8. Test With a Known-Good Compatible Module

When authorized and available, install a known-good module of the same approved type.

  • If the known-good module is recognized, the original module is likely defective.
  • If neither module is recognized, the problem may involve the module bay, host communication, power, configuration, or system software.

Do not repeatedly insert and remove modules while the machine is powered unless permitted by the applicable operating instructions.

Expected outcome: Testing isolates the problem to the original module or the anesthesia machine.

If the known-good module works correctly, remove the failed module from service and send it for evaluation.

9. Test the Module in Another Compatible Host

When permitted by facility policy, test the suspect module in another verified compatible Mindray host.

  • If the module fails in both systems, suspect module failure.
  • If the module works in another system, suspect the original machine’s module bay, configuration, communication path, or internal power supply.

Do not use this substitution test unless compatibility has been confirmed.

Expected outcome: The failure follows either the module or the anesthesia machine.

10. Complete an Operational Verification

After recognition is restored:

  • Confirm that the correct CO2 and agent parameters appear.
  • Verify waveform and numeric stability.
  • Confirm that the sampling pump operates normally.
  • Check for sampling-flow, water-trap, or occlusion alarms.
  • Verify CO2 using an approved test source or simulator.
  • Verify agent identification and concentration using approved test equipment when applicable.
  • Complete the required anesthesia-machine checkout.

Expected outcome: The module is recognized, measurements are accurate, alarms function, and the machine passes checkout.

If verification fails, stop and escalate the device for repair.

If the Problem Persists

If reseating, compatibility verification, accessory inspection, safe restart, and known-good substitution do not restore recognition, common external causes have been ruled out.

The problem may involve:

  • A failed gas module
  • Damaged module-bay contacts
  • Loss of module power
  • Internal communication failure
  • Software or configuration problems
  • An internal host-interface fault

The anesthesia machine should be:

  • Removed from service
  • Labeled Out of Service
  • Sent for qualified repair or bench evaluation

Do not disassemble the module or anesthesia machine without the appropriate Mindray service documentation, training, and test equipment.

Knowing when to stop and escalate is proper troubleshooting.

Clinical Use Tip

Never troubleshoot gas-module recognition on an active patient. Transfer monitoring or patient support first, then evaluate the module under controlled conditions with independent test equipment.

Work Order Documentation (CCR Method)

CCR = Complaint, Cause, Resolution

Complaint

What was reported by the clinical staff.

Example:
"Anesthesia staff reported that the WATO EX Series did not recognize the installed multi-gas module and CO2 and agent values were unavailable."

Cause

What was observed during troubleshooting.

Example:
"The gas module remained unrecognized after reseating and restarting, but a known-good compatible module was detected normally in the same module bay."

Resolution

What action was taken.

Example:
"Removed the failed gas module from service, installed a verified compatible replacement, completed gas-measurement testing and system checkout, and returned the anesthesia machine to service."

Helpful Details to Include (If Known)

  • Complete displayed message recorded
  • WATO EX model and serial number recorded
  • Module model, part number, and serial number recorded
  • Module fully reseated
  • Module bay inspected
  • Connector condition documented
  • Water trap and sampling line inspected
  • Known-good module tested
  • Suspect module tested in another compatible host
  • Unusual heat, smell, or fluid contamination noted
  • CO2 measurement verified
  • Agent measurement verified
  • Full system checkout completed
  • Final device and module status documented

Final Thought

Protect the patient first, then separate module-recognition problems from sampling failures. Verify installation, compatibility, accessories, and substitution results before suspecting an internal machine fault. Clear CCR documentation supports safe repair decisions and prevents unnecessary component replacement.

That is successful troubleshooting.
